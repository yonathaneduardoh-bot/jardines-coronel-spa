# Jardines Coronel SPA

Sitio web corporativo para Jardines Coronel SPA.

## Estructura

- `index.html`: pagina principal.
- `css/`: estilos del sitio.
- `js/`: comportamiento e interacciones.
- `assets/images/`: imagenes usadas por la pagina.

## Publicacion

Este sitio es estatico, por lo que puede publicarse en Netlify conectando este repositorio desde GitHub.

Configuracion recomendada en Netlify:

- Build command: dejar vacio.
- Publish directory: `.`.

## Flujo recomendado

1. Editar los archivos localmente.
2. Guardar cambios con Git.
3. Subir a GitHub.
4. Dejar que Netlify despliegue automaticamente desde GitHub.
